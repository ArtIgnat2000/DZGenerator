# Комплект для переноса V-labs

## Что загрузить в новый чат

Минимум: `V-labs-generator.html` и `Промпт-для-нового-чата.md`.

Удобнее загрузить архив `V-labs-перенос.zip` целиком и написать: «Распакуй архив, прочитай вводный промпт и продолжим работу с текущим генератором».

## Состав

- `V-labs-generator.html` — актуальное приложение, единственный необходимый исполняемый файл. HTML, CSS, JS и изображения встроены.
- `V-labs-инструкция.md` — руководство пользователя.
- `Промпт-для-нового-чата.md` — контекст, требования, история решений и ссылки.
- `tests/` — браузерные проверки. Нужны Python, Playwright, Chromium и PyMuPDF. Перед запуском изменить жёстко заданные пути `/home/user` при необходимости. Тесты генерируют временные файлы. Это не обязательная часть для работы приложения.
- `previews/` — исходные JPEG-превью шести проектов, уже встроенные в генератор.
- `previous-letters/` — ранее подготовленные письмо, мобильный HTML и шестистраничный PDF для Ивана; образцы, не исходник генератора.

## Важно: ваши данные браузера

Скачанный генератор НЕ содержит ваши локально введённые письма и профили. Они находятся в localStorage вашего браузера.

Перед переносом на другое устройство/в другой браузер:
1. Откройте используемый генератор.
2. «Настройки» → «Скачать резервную копию».
3. Сохраните JSON рядом с архивом. При необходимости приложите в новый чат, учитывая, что он содержит имена и тексты заданий.
4. На новом устройстве откройте генератор → «Настройки» → «Восстановить из файла».

Вложения `.sb3`, PDF и картинки в JSON не включены. Переносите реальные файлы отдельно.

## Источник истины для кода

Редактировать `V-labs-generator.html` напрямую. Не пересобирать из старых промежуточных заготовок: они могут не содержать последних исправлений печати и сохранения черновиков.

Встроенный ключ localStorage: `vlabs-homework-v1`. Версия структуры JSON: `1`.

Текущая архитектура: DOM-форма → объект `state` → генерация HTML письма и предпросмотра. `sections()` создаёт смысловые блоки, `emailInner()` — почтовую вёрстку, `documentHtml()` — автономный HTML и печатную версию, `paginatePrint()` — разбиение печатной версии. Профили содержат собственные черновики; `history` — снимки писем и настроек. Массивы `projects`, `presentations`, `skills` задают портфолио; `ASSETS` содержит data URI превью.

Отдельный сервер, аккаунты и API не нужны. Живое превью при желании запускается обычным статическим HTTP-сервером. Сервер предыдущего чата не является частью переносимого комплекта.
