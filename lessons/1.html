Урок 1. События (Events)

Научиться запускать программы по разным триггерам.

Изучаемые блоки

  • когда щёлкнут по зелёному флагу
  • когда нажата клавиша
  • когда щёлкнут по спрайту
  • когда получено сообщение → отправить сообщение

Практика на уроке

  • Создать интерактивную сценку: при нажатии на зелёный флаг — солнце выходит
  • при клике по облаку — идёт дождь
  • при нажатии пробела — появляется радуга (через сообщение).
Ключевая идея: Программа не всегда начинается с зелёного флага — она может реагировать на действия!

Игры, которые собираем

Солнце и дождь

Интерактивная сценка: клики, клавиши, таймер и сообщения меняют погоду — дождь, гром, ветер и радугу.

Скачать игру для Scratch (.sb3)

Открой файл в Scratch 3.0: Файл → Загрузить с компьютера. Проект отмечен знаком V Labs, подсказки по клавишам — в заметках рядом с блоками.

Радуга по сообщению

Радуга появляется по пробелу через сообщения.
