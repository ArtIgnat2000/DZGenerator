# Концепция: уроки Scratch → генератор → сайт школы

**Статус:** концепция, v1.0 (19 ноября 2026)
**Связанные документы:** `README.md` (правила проекта, версионирование),
`V-labs-инструкция.md` (работа с генератором)

## 1. Проблема

Программа курса Scratch (8 уроков) живёт на сайте школы как текст.
Материалы к урокам (игры, фоны, спрайты, скрипты) хранятся разрозненно.
Домашние задания собираются в генераторе вручную, без связи с программой курса.
Учитель тратит время на подготовку и пересказку материалов, ученик не видит
единой картины «урок → игра → домашка».

## 2. Видение: «Учебный конвейер»

**Урок → Материалы → Письмо с домашкой → Доступ ученика.**

Три части связывает один источник данных — карточка урока:

1. **Генератор** собирает письмо по карточке урока в 2 минуты.
2. **Сайт школы** показывает материалы урока (игры, фоны, спрайты, скрипты).
3. **Ученик** переходит из письма на страницу урока и работает с материалами.

## 3. Карточка урока (модель данных)

Каждый урок — структурированная запись:

| Поле | Что внутри | Пример (Урок 1) |
|---|---|---|
| `id` | Номер урока | `1` |
| `title` | Название | События (Events) |
| `goal` | Цель | Научиться запускать программы по триггерам |
| `blocks` | Изучаемые блоки | когда щёлкнут по зелёному флагу; когда нажата клавиша… |
| `practice` | Практика (шаги) | Солнце выходит; дождь по клику; радуга по пробелу |
| `idea` | Ключевая идея | Программа не всегда начинается с флага |
| `games` | Игры на выбор (2–3) | «Солнце и дождь», «Радуга по сообщению»… |
| `materials` | Фоны, спрайты, скрипты, объяснение | Ссылки на файлы и страницы сайта |

Карточку читают и генератор, и сайт — один источник, два представления.

### Программа курса (8 уроков)

1. **События (Events).** Цель: запускать программы по триггерам. Блоки: зелёный флаг,
   нажатие клавиши, клик по спрайту, сообщения. Практика: солнце выходит по флагу,
   дождь по клику на облако, радуга по пробелу через сообщение. Идея: программа
   реагирует на действия, а не всегда начинается с флага.
2. **Движение (Motion).** Цель: управление положением и направлением. Блоки: двигаться,
   повернуть, идти в x:y:, направиться к, оттолкнуться от края. Практика: лабиринт
   со стрелками, стены отталкивают, финиш — «Победа!». Идея: движение — это точное
   позиционирование.
3. **Внешность (Looks).** Цель: внешний вид спрайта и сцены. Блоки: сказать, сменить
   костюм, размер, показать/спрятать. Практика: история с персонажем (рад → грустен →
   удивлён), второй персонаж появляется/исчезает. Идея: внешность — это «театр».
4. **Звук (Sound).** Цель: звуковое сопровождение. Блоки: играть звук, ждать, громкость.
   Практика: мелодия на клавишах (робот поёт ноты по клавишам 1–5), громкость, автоплей мелодии.
   Идея: звук делает проект живым.
5. **Управление (Control).** Цель: логика выполнения. Блоки: повторять, навсегда,
   если…то, ждать, клоны. Практика: салют из клонов (клоны взлетают, вспыхивают
   и исчезают). Идея: управление — «мозг» программы.
6. **Сенсоры (Sensing).** Цель: «чувствовать» окружение. Блоки: касается?, расстояние,
   спросить и ждать, ответ, мышь. Практика: викторина (имя, проверка ответа),
   герой следует за мышью. Идея: сенсоры — «органы чувств» спрайта.
7. **Операторы (Operators).** Цель: числа, текст, логика. Блоки: +, −, ×, ÷, сравнения,
   и/или/не, случайное, объединение строк. Практика: калькулятор удачи (1–100,
   «Ты везунчик!» при > 80). Идея: операторы — «математика и логика» в Scratch.
8. **Данные (Data).** Цель: хранить и использовать информацию. Блоки: переменные,
   списки. Практика: список покупок (спросить → добавить в список → показать список).
   Идея: переменные — память программы, списки — «коробки с записками».

## 4. Генератор: «Урок» как кнопка

Во вкладке «Задание» появляется выбор урока (1–8). Нажатие заполняет письмо:

- тема, цель и практика — из карточки урока (можно поправить);
- домашнее задание — из практики урока;
- подсказка — из «ключевой идеи» или блока урока;
- ссылка на страницу урока на сайте + ссылка на выбранную игру.

**«Игра на выбор»:** для каждого урока 2–3 игры, учитель выбирает под конкретного
ребёнка (одному нравится лабиринт, другому — метеориты). Подготовка к уроку:
выбрал урок → выбрал игру → письмо готово.

Ограничения сохраняются: формулировки учителя не переписываются, пустые блоки
скрываются, файлы передаются по ссылкам на Яндекс Диск (см. `V-labs-инструкция.md`).

## 5. Сайт школы: материалы по урокам

На сайте — страница каждого урока:

- **Игры:** несколько вариантов на урок, превью, описание, кнопка «Открыть проект Scratch»;
- **Фоны и спрайты:** галерея с кнопкой «Скачать» (PNG/SVG);
- **Готовые скрипты:** блоки картинкой + пошаговое объяснение «почему так»;
- **Объяснение темы:** коротко, наглядно, с визуалом.

Файлы лежат в репозитории сайта и отдаются как статика (GitHub Pages) — просто
и надёжно. Генератор ссылается на них готовыми ссылками.

## 6. Дизайн «в стиле Пиксара»

Тёплый, объёмный, дружелюбный 3D-стиль: мягкий свет, округлые формы,
живые персонажи-проводники. Каждый урок — свой цвет и свой герой-проводник.
Домашка в письме оформлена в том же стиле — ученик узнаёт «свой» урок
с первого взгляда.

**Важно:** используются только оригинальные персонажи и иллюстрации,
вдохновлённые стилем, без персонажей и логотипов Pixar (авторские права).

## 7. Личный кабинет ученика (будущее)

Честно про ограничения: на статическом GitHub Pages настоящих аккаунтов нет.

- **Этап 1 (без сервера):** «кабинет» на том же устройстве — ученик открывает сайт,
  видит свои уроки, игры и прогресс (хранится в браузере). Просто, но не
  синхронизируется между устройствами. Даёт ~80% пользы.
- **Этап 2 (с сервером):** полноценные аккаунты, прогресс, домашние задания
  с отметками. Отдельный этап — когда статики уже мало.

## 8. Сценарии

**Учитель:** после урока выбирает «Урок 5: Управление» + игру «Метеоритный дождь»
→ письмо с домашкой и ссылкой на материалы собрано → отправляет (ссылка на файл —
Яндекс Диск или ссылка на страницу урока).

**Ученик:** открывает письмо → переходит на страницу урока → играет, качает
спрайты, смотрит скрипты → делает домашку.

**Родитель:** видит аккуратное письмо + ссылку на материалы, понимает, чем
занимается ребёнок.

## 9. Дорожная карта

1. **Карточки 8 уроков** в генераторе (шаблоны + выбор игры). ✅ Реализовано в v1.2.0:
   выбор урока подставляет тему, условие и подсказку; выбор игры добавляет её
   в материалы (ссылку на Яндекс Диск вставляет учитель).
2. **Страницы уроков на сайте** с играми, фонами, спрайтами, скриптами. ✅ Сделана основа в v1.3.0: `lessons/index.html` + восемь страниц (блоки, практика, ключевая идея, игры урока, редактор Scratch, печать); страницы собираются из данных генератора. Осталось наполнить галереей фонов/спрайтов и готовыми скриптами.
3. **Общий стиль** (герои, цвета, визуал).
4. **Кабинет ученика** (локальный, без сервера).
