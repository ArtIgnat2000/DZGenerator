Материалы к заданию

Ссылки попадут в письмо. Удобнее всего загрузить файлы в Яндекс Диск и вставить сюда ссылку — тогда файл откроется прямо из письма, без вложений.

Как получить ссылку на Яндекс Диске: загрузите файл в Диск → кликните по файлу правой кнопкой → «Поделиться» → «Скопировать ссылку». Вставьте её в поле ниже. Проверьте, что доступ открыт по ссылке, иначе получатель не откроет файл.
Генератор сохраняет только названия файлов. Сами файлы не загружаются, не хранятся в резервной копии и не переносятся в почту. Если не хотите прикреплять файлы вручную — загрузите их в Яндекс Диск и добавьте ссылку выше.

Предпросмотр письма
Предпросмотр показывает версию для телефона/браузера. Почтовая копия — без тяжёлых изображений. Вложения нужно прикрепить вручную.

Письмо готово. Как его отправить?

В Яндекс Почту — в тело письма

  1. Нажмите «Скопировать для почты».
  2. Откройте новое письмо и вставьте содержимое обычным Ctrl+V, не как простой текст.
  3. Скопируйте тему отдельной кнопкой «Тема ↗».
  4. Файлы по ссылкам уже в письме — ничего прикреплять не нужно. Если файлы выбраны локально, прикрепите их вручную.
  5. Сначала отправьте письмо себе и проверьте оформление.

Почтовый редактор может немного изменить отступы. Если браузер не разрешает копирование, генератор предложит ручное копирование.

Файлы по ссылке (Яндекс Диск)

  1. Загрузите файл в Яндекс Диск.
  2. Кликните по файлу правой кнопкой → «Поделиться» → «Скопировать ссылку».
  3. Вставьте ссылку во вкладке «Дополнительно» и укажите название.
  4. Проверьте, что доступ открыт по ссылке, — иначе получатель не откроет файл.

Ссылка попадёт в письмо, и файл откроется прямо из него — без вложений и лимитов размера.

В мессенджер или на телефон

«Скачать HTML» сохраняет письмо со встроенными превью. Файл открывается в браузере, но некоторые мессенджеры не показывают HTML. В этом случае удобнее PDF.

Сохранить PDF

Нажмите «Печать / PDF» → в окне браузера выберите «Сохранить как PDF». Печатная версия распределяет материал по смысловым страницам; карточки остаются целыми. Отключите колонтитулы браузера, включите фоновую графику. Проверьте предпросмотр: очень длинный текст может занять больше страниц.

Не потерять данные

В «Настройках» скачивайте резервную копию. Очистка данных браузера может удалить локальные черновики. Встроенный просмотрщик файлов может запрещать сохранение и копирование — скачайте генератор и откройте его в обычном браузере.
