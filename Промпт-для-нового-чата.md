# Вводный промпт для продолжения проекта V-labs

Я преподаватель школы программирования V-labs. Мы продолжаем уже начатый проект — локальный генератор фирменных писем с домашними заданиями. Не создавай всё заново: сначала изучи приложенные файлы, затем уточни, что я хочу изменить, если я ещё не указал конкретную задачу.

## Что я прикладываю

Главный актуальный файл — **V-labs-generator.html**. Это полностью самостоятельное приложение с HTML, CSS, JavaScript и встроенными JPEG-превью. Он является источником актуального кода, его можно редактировать напрямую. Вспомогательные старые скрипты из предыдущего чата для его сборки не нужны.

Также есть **V-labs-инструкция.md**, технический файл **ПЕРЕНОС-ПРОЕКТА.md** и тесты. Если я прислал ZIP, распакуй его. В папке `previous-letters` лежат предыдущие письма и PDF как примеры содержания и оформления, а не актуальные исходники генератора.

Не рассчитывай на файлы, браузерные данные и работающий сервер из предыдущего чата. Если приложений нет, попроси загрузить как минимум V-labs-generator.html.

## Моя задача

Я регулярно отправляю ученикам и родителям домашние задания по **Scratch 3.0**. После каждого урока меняются номер, тема, условие, подсказки, срок. Иногда прикладываю файлы, например проекты `.sb3`, картинки, PDF, или отправляю ссылки.

Нужен удобный генератор: я заполняю переменные поля, он собирает письмо в фирменном стиле V-labs. Основной канал — **Яндекс Почта в браузере**: получатель должен видеть письмо сразу в теле сообщения, без перехода на сайт и без открытия HTML-вложения. Дополнительно нужна версия для отправки файлом на телефон и PDF.

## Стиль

- Сдержанное, аккуратное оформление, вызывающее доверие: тёмно-синий, бирюзовый, белый, ясная иерархия. Не использовать логотипы McKinsey или аудиторов: это был ориентир по качеству, не принадлежность к ним.
- Текст тёплый, простой, уважительный и по-товарищески, без фамильярности и канцелярита, «с душой».
- Пример начала: «Иван, привет)» / «Добрый день, родители.»
- Пример завершения: «Если что-то не получится, напиши, на каком шаге застрял. Разберёмся вместе. До встречи на занятии!»
- Обычная домашка — короткая. Большое портфолио не вставлять каждый раз: оно включается отдельно.
- Мои формулировки не переписывать автоматически через ИИ.

## Что уже реализовано

В одном локальном HTML-файле, без установки, аккаунта, API, CDN и обязательного интернета:

1. Форма: профиль, имя, номер задания, режим письма, тема, условие, подсказка, проверка результата, срок датой или словами, личный комментарий.
2. Пустые необязательные блоки скрываются. Срок словами имеет приоритет над датой. Личный комментарий заменяет стандартное вступление.
3. Предпросмотр, режимы ширины «Компьютер» / «Телефон».
4. Настройки школы, сайта, предмета, приветствия с `{имя}`, вступления, завершения, подписи.
5. Профили учеников: свои текущие черновики и расписание. Общие настройки оформления и текста — на всё приложение.
6. Автосохранение в localStorage, история сохранённых редакций. Кнопка «Следующее задание» сохраняет прошлое письмо, увеличивает номер, очищает переменное содержимое, срок, материалы и отключает портфолио. Расписание как опция может остаться включённым.
7. Открытие истории сохраняет текущую редакцию и открывает рабочую копию выбранного письма. В истории также сохраняются настройки на момент создания версии.
8. Ссылки с проверкой http/https. Выбор локальных файлов сохраняет только их названия для списка вложений. Сами файлы нужно вручную прикрепить в Яндекс Почте или мессенджере.
9. «Скопировать для почты»: Clipboard API с text/html и text/plain; резервный режим ручного копирования. Почтовая копия использует табличную вёрстку, inline-стили, не содержит тяжёлых превью, но сохраняет ссылки и описания.
10. «Скачать HTML»: автономное адаптивное письмо со встроенными превью.
11. «Печать / PDF»: отдельный документ с осмысленными страницами и скриптом измерения/распределения блоков, а не простая печать длинного письма. Пользователь сохраняет PDF через окно печати браузера. Если новое окно запрещено — скачивается HTML для печати.
12. JSON-резервная копия, проверка структуры при восстановлении. Восстановление заменяет данные, не объединяет. Нет облачной синхронизации.
13. Встроенная инструкция «Как отправить?».
14. Курсы (`COURSES`): переключатель над уроками, курс 1 «Основы Scratch» по умолчанию, курс 2
    «Разработка игр» — восемь уроков-механик с текстами и страницами `lessons/course-2/`, курс 3
    «Своя игра» пока закрыт. У курса 2 есть восемь демо-игр и восемь заготовок
    (`lessons/course-2/games/` и `practice/`), а разгадка — сама демо-игра. Шаги миссии курса 2:
    «Сыграй — Найди блок — Придумай».

## Критически важное требование к PDF

Ранее я был очень недоволен автоматической нарезкой PDF: разрывались связанные блоки, нарушалась логика. Это уже исправляли. Не возвращайся к простой печати длинного HTML с произвольными разрывами.

Карточки проектов должны оставаться целыми: превью, название, описание и ссылка вместе. Домашнее задание — вместе с подсказкой, проверкой и сроком, насколько позволяет объём. Заголовки не должны оставаться одинокими внизу страницы. Длинный текст не обрезать. Проверять фактический PDF, число страниц, границы контента, ссылки и читаемость на телефоне.

В генераторе задан мобильный печатный размер 520 × 980 CSS px. Обычное короткое письмо тестировали на одной странице; расширенное с примерами — на шести. Эти числа не гарантируются для любого текста. В окне печати нужны масштаб 100%, отключённые браузерные колонтитулы, включённые фоны.

## Технические оговорки и текущий статус

- Данные сохраняются в браузере, а не внутри HTML-файла. Для переноса моих реальных профилей/писем потребуется отдельная JSON-копия из «Настроек».
- Нельзя обещать автоматическое прикрепление файлов, отправку через Яндекс Почту или синхронизацию — этого нет.
- Нельзя гарантировать точное сохранение каждого отступа во всех почтовых редакторах. Реальную доставку в Яндекс Почте пользователь ещё должен проверить письмом самому себе.
- Встроенный просмотрщик чата может блокировать localStorage, clipboard, загрузки и окна. Рабочий вариант — скачать генератор и открыть в обычном Chrome/Edge.
- HTML на телефоне поддерживается не всеми мессенджерами, поэтому предусмотрен PDF.
- В предыдущем чате автоматические браузерные проверки прошли: смена ученика и его черновика, автосохранение после обновления, история, ссылки без javascript:, список вложений, JSON-структура резервной копии, копирование HTML без тяжёлых картинок, мобильная ширина 390px без горизонтального скролла, печать короткого/расширенного/очень длинного задания без обрезки в тесте. Полное ручное тестирование пользователем не завершено. Не утверждай, что все возможные ситуации уже проверены.

## Как продолжать

Сначала изучи актуальный HTML и инструкцию. Дальше вноси точечные изменения по моему следующему запросу, сохраняя готовый функционал. Если запускаешь превью, сервер должен слушать 0.0.0.0, а не только localhost. Для выдачи результата обязательно сохраняй скачиваемую, полностью автономную версию HTML. Проверяй ошибки JavaScript, копирование, сохранение и печать после изменений. Не создавай заново приложение из одного лишь описания, когда приложен рабочий файл.
