# DZGenerator — генератор домашних заданий V-labs

Локальный генератор фирменных писем с домашними заданиями по Scratch 3.0.
Один автономный файл `V-labs-generator.html` (HTML + CSS + JS + встроенные превью),
без установки, аккаунта, API и CDN. Сайт: https://artignat2000.github.io/DZGenerator/

## Правила проекта

1. **Каждый релиз увеличивает номер версии.** Номер хранится в файле `VERSION`
   и в константе `VERSION` внутри `V-labs-generator.html` — они должны совпадать.
2. **Номер релиза обязательно отображается на сайте** — в шапке генератора
   (бейдж «Локально · Без аккаунта · Без ИИ · vX.Y.Z»), чтобы было ясно,
   какой релиз работает на сервере.
3. **Источник правок — `V-labs-generator.html`.** Не пересобирать из старых
   заготовок (`previous-letters/generator-base.html` — только для справки).
4. **Формулировки пользователя не переписывать через ИИ.** Текст задания
   попадает в письмо как есть.
5. **PDF не резать произвольно.** Карточки проектов — целиком, заголовки не
   остаются одни внизу страницы, длинный текст не обрезается.
6. **Не обещать невозможного:** нет автоотправки через Яндекс Почту,
   авто-прикрепления файлов и облачной синхронизации. Данные — только
   в localStorage браузера + JSON-резервная копия.
7. **Урок принадлежит курсу.** В черновике это пара `course` + `lesson`
   (курс 1 — по умолчанию, старые данные без `course` читаются как курс 1).
   Данные курсов — `COURSES` в генераторе; страницы курса N лежат
   в `lessons/course-N/`, курс 1 — в `lessons/` как раньше.

## Курсы

Три курса повторяют путь «пользуюсь — дорабатываю — создаю»:

| Курс | Чему учит | Уроки | Состояние |
|---|---|---|---|
| 1. Основы Scratch | восемь групп блоков | 8 | игры, заготовки, разгадки, страницы |
| 2. Разработка игр | восемь игровых механик | 8 | демо-игры, заготовки, страницы, письма |
| 3. Своя игра | спринты по своей игре | — | следующий этап |

В генераторе над кнопками уроков стоит переключатель курсов. Курс 1 выбран
по умолчанию; курс 3 пока недоступен. Смена курса убирает выбранный урок
(текст, который преподаватель написал сам, остаётся), урок выбирается уже
внутри курса. Ссылка со страницы урока открывает генератор с курсом:
`V-labs-generator.html?course=2&lesson=1`; для курса 1 по-прежнему
достаточно `?lesson=1`.

У курса 2 — свои демо-игры и заготовки: восемь пар в
`lessons/course-2/games/` и `lessons/course-2/practice/`. Демо-игра — это
и игра до урока, и разгадка практики: на занятии собираем ровно её. Шаги
миссии курса 2 называются «Сыграй», «Найди блок», «Придумай»: третий шаг
готовит замысел своей версии игры, а не правку одного числа.

## Игры Scratch (.sb3)

В `lessons/games/` лежат восемь автономных проектов Scratch 3.0 — по одному на тему курса.
Каждый проект — рабочая мини-игра на 100+ блоков, в которой больше всего блоков из категории
своего урока:

| Файл | Игра | Блоки темы | Что внутри |
|---|---|---|---|
| `01-events.sb3` | Солнце и дождь | События | флаг, клавиши, клики по спрайту и сцене, смена фона, таймер, сообщения и «передать и ждать» |
| `02-motion.sb3` | Космический маршрут | Движение | шаги, повороты, координаты, плавное скольжение, «повернуться к», отскок от края |
| `03-looks.sb3` | Театр настроений | Внешность | костюмы, фоны, размер, эффекты, показаться/спрятаться, слои, реплики |
| `04-sound.sb3` | Музыкальный инструмент | Звук | восемь нот и барабан, громкость, высота звука, стерео, «играть до конца»; три мелодии из «Звёздных войн» — Имперский марш, Cantina Band и главная тема |
| `05-control.sb3` | Метеоритный дождь | Управление | циклы, условия, ожидания, клоны, уровни, «стоп» |
| `06-sensing.sb3` | Следопыт за мышью | Сенсоры | мышь, клавиши, касания спрайта, края и цвета, расстояния, вопрос и ответ, таймер, дата и время |
| `07-operators.sb3` | Математический оракул | Операторы | арифметика, случайные числа, сравнения, и/или/не, строки, округление |
| `08-data.sb3` | Дневник желаний | Данные | переменные и список: добавить, вставить, заменить, найти, удалить, показать |

Все проекты помечены знаком **V Labs**: это отдельный спрайт «V Labs» в правом верхнем углу сцены
(он всегда остаётся поверх остальных) и заметка «V Labs · Урок N» в области кода каждого спрайта
и сцены — в ней же перечислены клавиши управления. Управление рассчитано на любую раскладку
клавиатуры: только цифры, стрелки, пробел и мышь.

Проекты содержат оригинальные SVG-иллюстрации из базовых фигур (без текста, фильтров и
градиентов — картинка одинакова на сцене и в редакторе костюмов), а игровой код собран только
из стандартных блоков Scratch без расширений и пользовательских блоков. Звуковой проект
содержит встроенные ноты; внешние ссылки не требуются. На страницах уроков есть кнопка скачивания.

Исходник-сборщик: `scripts/build-games.py`. Игры описаны в нём короткими сценариями
(`sprite.when(flag(), say_for('Привет!', 2), …)`), сборщик сам проверяет ссылки на костюмы,
звуки, спрайты и сообщения. Пересобрать пакеты после правки сценария или графики:

```
python3 scripts/build-games.py          # пересобрать и показать число блоков по категориям
python3 scripts/build-games.py --check  # проверить, что .sb3 соответствуют сборщику
```

Чтобы открыть проект, скачайте `.sb3` и выберите в Scratch 3.0 «Файл → Загрузить с компьютера».

Рядом с каждой игрой лежит её кадр — `01-events.png … 08-data.png` (960×720). Он показывается в письме
«Готовимся к уроку»: почтовые программы не отображают SVG, поэтому нужен PNG. Кадр собирается из самой игры:
`python3 scripts/build-shots.py` читает `project.json` из `.sb3` и складывает фон, спрайты и переменные
в SVG-сцену 480×360 (по умолчанию в `/tmp/vlabs-shots`). SVG нужно один раз открыть в браузере и сохранить
снимок в `lessons/games/` под именем игры. После правки графики или расстановки спрайтов кадр стоит обновить.

В `lessons/course-2/games/` — восемь демо-игр, по одной на механику. Каждая игра — рабочая
мини-игра на 40–124 блока, в которой есть законченное правило победы, таймер или жизни.

| Файл | Игра | Механика | Что внутри |
|---|---|---|---|
| `01-chase.sb3` | Догонялки | герой и управление | лис ходит стрелками, ловит звёзды, сцена считает 30 секунд |
| `02-platform.sb3` | Платформер | прыжок и гравитация | переменная «Скорость», прыжок, приземление на платформы, три монеты |
| `03-maze.sb3` | Лабиринт | стены и столкновения | шаг и проверка касания стены, три ключа, дверь |
| `04-catcher.sb3` | Ловец | очки, жизни и таймер | яблоки и бомбы-клоны, корзина, три жизни |
| `05-pursuit.sb3` | Погоня | враг с простым поведением | тень идёт к лису, ключи и три жизни |
| `06-shooter.sb3` | Тир | клоны и пули | пушка за мышкой, пуля-клон, мишени-клоны, счёт |
| `07-quest.sb3` | Приключение | уровни и смены сцен | два фона, три предмета, сообщение «Уровень 2», дверь |

Рядом с каждой игрой лежит кадр `NN-name.png` (960×720) для письма. Кадры собираются из
`project.json` командой `python3 scripts/build-shots.py --course2`: она пишет SVG 480×360, который
нужно открыть в браузере и сохранить PNG 960×720 — так же, как кадры курса 1.

Исходник-сборщик: `scripts/build-course2.py`. Он импортирует блоки, графику и звуки из
`scripts/build-games.py`, описывает восемь игр и получает заготовки, убирая программу.

```
python3 scripts/build-course2.py          # пересобрать 8 игр и 8 заготовок
python3 scripts/build-course2.py --check  # проверить, что файлы соответствуют сборщику (делает CI)
```

## Практика: заготовки и разгадки (.sb3)

У урока три проекта Scratch, и у каждого своё время:

| Проект | Где лежит | Когда ученик его получает |
|---|---|---|
| Игра-пример | `lessons/games/NN-тема.sb3` | до урока, в письме «Готовимся к уроку» |
| Заготовка | `lessons/practice/NN-тема-start.sb3` | до урока или в его начале |
| Разгадка | `lessons/practice/NN-тема-solution.sb3` | после урока, если попросит — письмом «Разгадка» |

**Заготовка** — проект практики без программы: герои, фоны и звуки на месте, блоков, переменных и списков нет.
В области кода главного героя лежит заметка «Что собираем на уроке» с шагами практики. Все ученики
стартуют с одной точки, а урок уходит на программу, а не на рисование.

**Разгадка** — тот же проект с готовой программой: только то, что собирают на уроке (12–41 блок).
В заметке у каждого спрайта — что делает его программа.

В курсе 2 разгадка — это демо-игра урока: отдельного файла `-solution.sb3` нет. Заготовка
`lessons/course-2/practice/NN-name-start.sb3` содержит тех же героев и фоны без программы,
а собрать на уроке нужно ровно демо-игру. Оба набора собирает `scripts/build-course2.py`.

| Урок | Практика | Герои | Что в разгадке |
|---|---|---|---|
| 1. События | Солнце и дождь | Солнце, Облако, Капля | флажок, клик по облаку, пробел, сообщения «Дождь» и «Радуга» |
| 2. Движение | Лабиринт | Жук, Стены, Финиш | стрелки поворачивают и ведут жука, стена отталкивает, у кристалла — «Победа!» |
| 3. Внешность | История с персонажем | Кубик, Звёздочка | реплики, три костюма, второй герой появляется по сообщению, смена фона |
| 4. Звук | Мелодия на клавишах | Робот | клавиши 1–5 — ноты, стрелки — громкость, пробел — песенка |
| 5. Управление | Салют из клонов | Искра | «навсегда», «если», клоны: взлетают, вспыхивают и удаляются |
| 6. Сенсоры | Викторина | Робот, Звёздочка | вопрос и ответ, «если … иначе», Звёздочка идёт за мышью |
| 7. Операторы | Калькулятор удачи | Кристалл | случайное число в переменной, «объединить», сравнение с 80 |
| 8. Данные | Список покупок | Корзина | список: очистить, добавить ответ, показать, длина и первый элемент |

В уроке 1 практика идёт на той же сцене, что игра-пример: так ученику проще привыкнуть. В остальных уроках
у практики свой сюжет на тех же блоках, поэтому игра-пример ничего не подсказывает заранее.

Оба файла собирает `scripts/build-practice.py`. Он берёт сборщик блоков, графику и звуки из
`scripts/build-games.py`, описывает разгадку, а заготовку получает из неё, убирая программу, — поэтому
герои и фоны в двух файлах всегда одинаковые.

```
python3 scripts/build-practice.py          # пересобрать 16 файлов
python3 scripts/build-practice.py --check  # проверить, что файлы соответствуют сборщику (делает CI)
node checks/play-practice.js               # пройти разгадки в движке Scratch; запускается вручную
```

`checks/play-practice.js` делает в разгадке то, что написано в практике урока (ведёт жука по лабиринту,
отвечает на вопросы викторины, записывает покупки), а в заготовке проверяет, что программы нет и флажок
ничего не меняет. Стенд тот же, что у `checks/play-missions.js`.

Название практики и текст письма «Разгадка» хранятся в `LESSONS`: поля `work` и `solve` (`look` — что
сравнить со своим проектом, `own` — что изменить по-своему).

**Разгадка до урока не выдаётся.** Ссылки на неё нет ни на страницах уроков (это проверяет CI), ни в письмах
«Готовимся к уроку» и «Задание по уроку». Но сайт открытый: файл лежит по предсказуемому адресу, и закрыть его
можно будет только вместе с личным кабинетом.

## Страницы уроков

`lessons/index.html` — обзор трёх курсов, `lessons/1.html … lessons/8.html` — уроки курса 1,
`lessons/course-2/1.html … 8.html` и `lessons/course-2/index.html` — программа курса 2.
Они **не пишутся руками**: их собирает `node scripts/build-lessons.js` из `COURSES`
в генераторе, чтобы данные уроков не расходились в двух местах.
Если меняете урок в генераторе — пересоберите страницы:

```
node scripts/build-lessons.js          # пересобрать
node scripts/build-lessons.js --check  # проверить, что страницы актуальны (делает CI)
```

Урок в генераторе — свойство письма (`course` + `lesson` в черновике). Материалы урока — страница урока
и игра `.sb3` — не хранятся в списке ссылок, а выводятся из выбранного урока, поэтому при смене урока
заменяются, а не копятся. Имя файла игры задаётся там же, в уроке (поле `file`): у курса 1 это
`lessons/games/`, у курса 2 — `lessons/course-2/games/`.

**Ссылка на страницу урока в письмо сама не попадает.** На сайте нет личного кабинета: со страницы урока
ученик может перейти к любому другому уроку и заглянуть вперёд. Поэтому галочка «страница урока на сайте»
в карточке урока выключена по умолчанию и включается преподавателем для конкретного письма. Игра отдаётся
прямой ссылкой на файл `.sb3`, а кадр игры — картинкой: они не ведут на страницы сайта.

Страницы автономны: один файл, встроенные стили, без CDN. Печать (Ctrl+P) даёт
чистый лист с уроком без шапки и кнопок.

## Письмо «Готовимся к уроку»

По выбранному уроку генератор собирает одно из трёх писем — переключатель в карточке урока:

- **«Готовимся к уроку»** — письмо ребёнку до урока. Сверху кадр игры и кнопка, затем миссия из трёх шагов
  по пять минут, необязательное «Хочу ещё» и список «Возьми на урок». Внизу — строка родителям. Письмо
  окрашено в цвет урока; слова в `[квадратных скобках]` в тексте шага выводятся блоком этого цвета.
  В курсе 1 шаги — «Сыграй», «Найди блок», «Измени одно число», в курсе 2 — «Сыграй», «Найди блок»,
  «Придумай».
- **«Задание по уроку»** — прежнее письмо после урока: тема, задание, подсказка, материалы.
- **«Разгадка»** — письмо по просьбе ученика после урока: кнопка с готовым проектом практики, три шага
  («Запусти», «Сравни со своим», «Сделай по-своему») и ссылка на заготовку, если хочется собрать заново.
  Выбор «Разгадки» не запоминается: следующее письмо снова начнётся с «Готовимся к уроку».

Галочка **«заготовка»** в карточке урока добавляет ссылку на заготовку: в письме «Готовимся к уроку» —
строкой в «Возьми на урок», в «Задании по уроку» — в материалы. По умолчанию она выключена.

Письмо одно на урок: похвала за прошедший урок («Несколько слов от себя») идёт в начале, а то, что нужно
доделать, — блоком «С прошлого урока» после миссии (поля «Тема задания» и «Что сделать», они необязательны).
Дата из поля «Дата урока» попадает в письмо строкой «Урок — …».

Текст миссии хранится в `LESSONS` (поле `prep`: `hook`, `intro`, `play`, `find`, `change`, `more`, `bring`
и `key` — ответы для преподавателя, в письмо не попадают), цвет урока — в полях `color` и `dark`.
Преподаватель может править текст миссии в форме; правка хранится в черновике (`prepText`) и сбрасывается
ссылкой «Вернуть текст урока».

Числа и названия блоков в миссиях взяты из программ игр, и это проверяется двумя способами:

```bash
python3 scripts/check-missions.py   # быстро, без запуска игр; входит в CI
node checks/play-missions.js        # проходит миссии в движке Scratch; запускается вручную
```

`scripts/check-missions.py` хранит список фактов, на которые опирается каждая миссия (спрайт, блок, число,
сколько раз встречается), и сверяет его и с `.sb3`, и с текстом миссии. Если изменить игру или текст и не
поправить вторую сторону, CI упадёт и назовёт урок. Меняете миссию — поправьте и список `FACTS`.

`checks/play-missions.js` запускает игры в настоящем движке Scratch (`scratch-vm` с отрисовкой) и делает то же,
что ученик: флажок, клавиши, клики, ответы на вопросы, правка числа в блоке. Как его подготовить, написано
в начале файла. Он не слышит звук и не видит, как игра выглядит в TurboWarp.

Игра по умолчанию открывается в браузере: галочка «игра открывается в браузере (TurboWarp)» включена, и кнопка
«Играть» ведёт на `https://turbowarp.org/?project_url=<адрес .sb3>` — игра запускается без скачивания и аккаунта.
Рядом с галочкой есть ссылка для проверки. Без галочки игра отдаётся файлом `.sb3` (кнопка «Скачать игру»).
Выбор — настройка `gameWeb`, он запоминается для всех писем и учеников.

Расписание занятий (`showSchedule`) включено по умолчанию и хранится в черновике ученика, то есть у каждого
ученика своё. Блок выводится, только если поле расписания заполнено. Формат письма переключает три остальных
раздела (флагманские проекты, презентации, направления), расписание он не выключает.

Умолчания 1.8.2 один раз применяются и к уже сохранённым данным (`adoptDefaults()`, отметка `defFix`): без этого
сохранённые значения перекрыли бы новые умолчания. После этого снятая галочка остаётся снятой.

Замысел и варианты, из которых выбран этот формат, — в `КОНЦЕПЦИЯ-ПИСЬМО.md`.

## Навигация по сайту

Принцип — один элемент на одно действие, без дублей. На сайте два раздела, и в шапке ровно два пункта:
**«Генератор заданий»** (стартовая страница, `index.html` перенаправляет на неё) и **«Уроки и игры»**.
Шапка одинакова на всех страницах, текущий раздел подсвечен. Раздел «Уроки и игры» начинается со списка
трёх курсов: у курса 1 — игры и страницы, у курса 2 — программа и страницы уроков, курс 3 — следующий этап.

**Генератор.** Урок выбирается в одном месте — рядом кнопок 1–8 «Урок курса» во вкладке «Задание»:

- клик по уроку собирает письмо «Готовимся к уроку»; переключатель в карточке урока меняет его на
  «Задание по уроку» (тема, задание и подсказка из программы, игра в материалах);
  страница урока добавляется в письмо только по галочке;
  последний выбор запоминается;
- выбор хранится в черновике ученика и переживает перезагрузку; другой урок заменяет материалы прежнего;
- текст, который преподаватель написал или поправил сам, не заменяется без явного нажатия
  «Подставить текст урока» (после него есть «Вернуть мой текст»); диалогов подтверждения нет;
- галочка на кнопке урока — письмо по нему уже есть в истории этого ученика;
- вкладки: «Задание» (что задать), «Материалы» (свои ссылки и файлы), «Настройки» (разделы письма,
  фирменный стиль, резервная копия), «История».

**Уроки и игры.** `lessons/index.html` — один список из восьми строк: урок и его игра идут парой.
На странице урока — переключатель уроков 1–8, кнопки «предыдущий / следующий» и листание клавишами ← →.
Ссылка «Преподавателю: собрать письмо…» открывает генератор с уже выбранным уроком
(`V-labs-generator.html?lesson=N`).

Шапка и переключатель уроков описаны в `scripts/build-lessons.js` (функции `head` и `steps`), шапка
генератора — в самом `V-labs-generator.html`. При добавлении раздела поправьте оба места.

## Хостинг и деплой

Сайт полностью статический, поэтому его можно раздавать любым хостингом. Сейчас он опубликован
на GitHub Pages, и решено пока там и оставаться. Заготовка на переезд (SourceCraft Sites,
Object Storage со своим доменом, база для кабинета) лежит в `ДЕПЛОЙ-ЯНДЕКС.md`; файлы
`.sourcecraft/sites.yaml` и `deploy-yandex.yml` выключены: первый никто не читает, второй
без секретов сразу выходит.

Адрес сайта в коде задан **в одном месте** — `const SITE=` в `V-labs-generator.html`. Все ссылки
внутри сайта относительные, поэтому сайт работает и из корня домена, и из подпапки. При смене
адреса меняется эта строка и пересобираются страницы уроков (`node scripts/build-lessons.js`).

| Файл | Что делает |
|---|---|
| `.sourcecraft/sites.yaml` | публикация репозитория на SourceCraft Sites (Яндекс, бесплатно, без своего домена) |
| `.github/workflows/deploy-yandex.yml` | выкладка в Yandex Object Storage при пуше в `main`; без секретов пропускается |

Базы данных у сайта нет и пока не нужно: данные живут в `localStorage` браузера. База появляется
вместе с личным кабинетом — это отдельный этап.
